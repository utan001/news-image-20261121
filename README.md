A program that draws one image summing up the world news of Saturday 21 November 2026: a newspaper front page with the date in large type, six stories with drawn pictures and short labels (Russia's barrage on Kyiv and missiles in Poland; the AI sell-off and Wall Street's correction; the ICJ's Myanmar genocide ruling; the claimed Riemann Hypothesis solution; COP31 in overtime; a pancreatic-cancer pill) and a strip of three more. Python 3 standard library only; the PNG is drawn pixel by pixel and is byte-for-byte deterministic (1024x1024, about 22 KB).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=<out dir> python3 main.py
```
